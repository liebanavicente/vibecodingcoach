# vibecodingcoach

Web de Miguel Liébana: clases de vibe coding para principiantes + curso gratuito "Vibe Coding desde Cero".

- Plan de negocio y currículo: [PLAN.md](./PLAN.md)
- Contenido del curso: [src/content/curso.ts](./src/content/curso.ts) — para publicar un módulo nuevo, rellena sus campos y pon `available: true`.
- Datos de contacto y enlaces: [src/lib/site.ts](./src/lib/site.ts)

## Desarrollo

```bash
npm install
npm run dev
```

Abre http://localhost:3000.
