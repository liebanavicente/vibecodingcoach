Cuatro IAs para vibe coding: puntos fuertes y puntos débiles.

Claude Code
+ Edita varios archivos del proyecto.
− Las sesiones largas pueden aumentar el consumo.

Codex
+ Delega tareas en la nube.
− Ese modo requiere configurar un entorno.

Kimi Code
+ Puedes usar sus modelos desde Claude Code.
− Cuotas y capacidades dependen del plan.

Antigravity
+ El agente trabaja en editor y navegador.
− Si vienes de otro editor, tienes que acostumbrarte.

Son ventajas y fricciones de uso, no un ranking de calidad. Algunas también afectan a otras herramientas.

Mismo prompt, mismo proyecto: compara el resultado. ¿Con cuál te quedas?
